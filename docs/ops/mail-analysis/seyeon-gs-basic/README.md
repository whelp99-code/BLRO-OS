## 개수

브리핑의 87은 시트 데이터 행이다. 소분류가 비어 있고 앞 기능의 상세만 이어진 행이 12개다.

- 데이터 밸런싱 3행, 디스크 격리 2행, 구성도 토폴로지 6행, 클러스터 관리 1행
- 이름이 있는 기능은 75개 (컴퓨트 33, 스토리지 24, 네트워크 11, 모니터링 7)
- csv/json의 75는 이 소분류 개수와 같다. 브리핑의 스토리지 29·네트워크 17·모니터링 8은 이어진 행을 기능으로 센 값에 가깝다

1/3 KEEP는 28개이다. 40개 안의 부분집합이고 75개의 37%이다. 브리핑 목표 28–30에 맞다.

## 주요 DROP

성능·고급·이기종으로 뺀 항목이다.

- 컴퓨트: CPU 최적화, NUMA, 메모리 압축, 대용량 페이지, 메모리 누수 보호, CPU/메모리 QoS, VM 자동 핫애드, SR-IOV NIC, vCenter 연동, 연결 클론, 즉시 전체 클론, TB 단위 표시, 실행 중 디스크 유형 변경, 클러스터 간 마이그레이션
- 스토리지: 다중 링크 부하 분산, FC 다중 경로, 이기종 호환, iSCSI 가상 디스크(외부·VMware 공개), 디스크 파티셔닝, 동적 프로비저닝, 티어링, 적응형 스트라이핑·배포, 디스크 QoS, I/O 파이프라이닝, 디스크 최적화, RDMA
- 네트워크: VXLAN, IPv6, 토폴로지 편집기, 트래픽 미러링, VXLAN 평면을 포함한 네트워크 상태 모니터링
- 모니터링: 점유 자원 표시(다른 모니터와 중복), 대규모 클러스터 컨트롤러 관리

1/3은 1/2에서 아래를 더 뺀다. CPU·메모리 오버커밋, DRS, 템플릿, 전체 클론, 호스트 이름 일괄 지정, 외부 스토리지 유형 선택, 공유 디스크, 데이터 밸런싱, 디스크 유지보수 서술, 가상 라우터, LLDP.

라우터 절은 1/2에만 둔다. IPv6 기능은 DROP이므로 라우터 절차는 IPv4 인터페이스, 정적 경로, SNAT/DNAT, DHCPv4, DNS, HA만 적었다.

## 시험비 절감 협의 포인트

상대 문장의 풀버전 시험비는 2,500만 원 이상(VAT 별도)이다. 이 숫자는 상대 문장이며 (주)베를로가 다시 계산하지 않았다. 절감액도 적지 않았다.

협의 때 시험 범위에서 빠지는 절차로 말할 수 있는 묶음은 다음과 같다.

1. 이기종: vCenter 관리, iSCSI로 외부·VMware에 LUN 공개, 이기종 호스트 혼합
2. 오버레이·주소: VXLAN, IPv6, 트래픽 미러링, 토폴로지 편집(vAD·vAF 포함)
3. 성능 장치·알고리즘: RDMA, SR-IOV, NUMA·대용량 페이지·메모리 압축, 티어링, 스트라이핑, I/O 파이프라이닝, CPU·메모리·디스크 QoS
4. 범위가 큰 이전: 클러스터 간 콜드·라이브 마이그레이션
5. 외부 스토리지 심화: FC 다중 경로, 다중 링크 부하 분산

1/3 최소판은 여기에 더해 가상 라우터(NAT·DHCP·HA), 템플릿·클론·DRS·오버커밋을 시험 항목에서 뺀다. 표준판(1/2)과 최소판(1/3) 중 어디를 인증 범위로 낼지는 재민 확정 사항이다.

매뉴얼은 KEEP 기능의 풀 가이드 절차를 남겼다. DROP 장은 삭제했다. 옵션 절은 기능 이름만 대분류별로 모아 한 장 분량으로 두었다.

## 매뉴얼에서 뺀 표기

- 풀 가이드 표지의 Creit Co., Ltd.와 작성자 이름은 고객면 문서에 넣지 않았다
- 채널 파트너 상호는 넣지 않았다
- 회사명을 적을 때는 (주)를 붙인다. 매뉴얼 본문은 제품 절차만 담아 국내 법인명을 적지 않았다
- 풀 가이드의 화면 캡처는 장과 그림의 대응이 본문 순서만으로는 확정되지 않아 넣지 않았다. 절차 문장만 남겼다
- 경보 정의 표 전체는 기능 목록의 소분류가 아니고, GPU·VXLAN·라우터 장애처럼 DROP 범위를 다시 끌어들여 수록하지 않았다. 클러스터 모니터 절에 경보가 있다는 문장만 두었다

## UNKNOWN

- 재민이 KEEP 목록을 확정하지 않았다. 선정은 브리핑의 휴리스틱을 따른 초안이다
- 시험기관이 매뉴얼에 적힌 메뉴를 모두 시험하는지, 기능 목록의 소분류 단위로 시험하는지는 확인되지 않았다. 1/2의 「다양한 스토리지 지원」은 유형 선택 절차가 있어 iSCSI·FC·NFS가 시험에 포함될 수 있다
- 디스크 유지보수 모드의 전용 메뉴 경로는 풀 가이드에 없다. 1/2 매뉴얼은 영향 점검 후 격리·제거로 이어진다고만 적었다
- 장애 위치 확인의 기능 설명은 연결 테스트이고, 풀 가이드 절차는 토폴로지 패킷 캡처이다. 매뉴얼은 가이드에 있는 캡처 절차를 적었다
- 인증·조달의 주체 법인, 시험기관, 일정은 이 작업에서 확정하지 않았다
- 기존 PR #6은 메일 분석 초안이다. 그 PR의 「구분안 실작성 보류」는 이번 작성 지시로 범위가 열린 상태이다. 이 폴더는 베이직 매뉴얼만 다룬다
