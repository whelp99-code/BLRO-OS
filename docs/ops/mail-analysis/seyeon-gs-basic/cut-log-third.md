## 번호 재매김

장 번호 1–5는 다섯 장이 모두 남아 그대로다. 부록 A를 빼서 장 번호 뒤에는 번호가 없다.

절 번호는 남은 절만 장 안에서 1부터 다시 매겼다. 위 KEEP 표가 옛 번호와 새 번호의 대응이다. 본문에서 1.6.2가 HA와 VM 고가용성에 중복돼 있던 것은 1.3.2와 1.3.3으로 갈랐다.

목차는 원본과 같이 수동 문단이다. `toc 1` / `toc 2` / `toc 3` 스타일과 탭을 유지한 채 40행으로 다시 썼다. 본문 제목과 목차 제목이 서로 있게 맞는지 확인했다. 1.1 하이퍼바이저만 원본처럼 목차 상위 행이고 본문 제목은 1.1.1이다.

절차 안의 1. 2. 3. 단계는, 그 절 안에서 단계를 빼지 않았으므로 원문 번호를 그대로 두었다. 원본 5.7 클러스터 모니터는 처음부터 2, 3, 5, 6, 1 순서였다. 이번 삭제와 무관해서 고치지 않았다.

Word 자동 번호가 삭제한 절과 이어져 있던 두 곳은 잘린 뒤에도 1부터 시작하도록 리스트 인스턴스만 분리했다. 번호 서식(abstract numbering)은 바꾸지 않았다.

- 스토리지 정책 단계: 앞에 있던 iSCSI 절 항목이 빠져 1부터 다시 센다.
- Host interface의 「관리 IP 설정」「관리 인터페이스 지정」: 스토리지 정책과 같은 리스트에 묶여 있던 것을 새 리스트로 분리해 1, 2로 다시 센다.
- Linux vmTools 단계: 앞에 있던 vCenter 절 항목이 빠져 1부터 다시 센다.

## 그림·표·상호참조

원본 본문에 `그림 N`, `표 N`, SEQ 캡션, 「N.N절 참조」가 없다. 다시 매길 그림 번호와 표 번호, 본문 상호참조가 없다.

표는 두 개였다. 개정 이력 표는 번호가 없고 표지 쪽에 그대로 두었다. 경보 정의 표는 부록과 함께 삭제했다. 남은 표는 개정 이력 1개다.

화면 캡처는 절 문단에 들어 있다. 지운 절의 캡처는 문단과 함께 빠졌고, 더 이상 참조하지 않는 미디어 70개도 패키지에서 뺐다. 남은 캡처의 그림 번호는 원래 없었다.

## 절 안에 남은 DROP 언급

절 단위로만 잘랐다. KEEP 절 안의 문장은 고치지 않았다.

- 2.3 VM IP주소 구성에 「템플릿 기반 배포에서는 IP 주소 풀을 입력하여…」 한 문장이 원문 그대로 있다. 템플릿 절 자체는 삭제했다.
- 3.4 맞춤형 스토리지 정책 설명에 복제본과 함께 「자동 QoS, 스트라이프 폭」이 원문에 있다. 디스크 QoS 절과 스트라이핑 절은 삭제했다.
