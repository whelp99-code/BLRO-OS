# Sangfor HCI 베이직 기능 선정 — 1/2 축소판

- 제품: Sangfor HCI(aSV) 6.10.0_R2
- 정본: `SANFOR_HCI_feature_list_v5.xlsx`의 소분류. 이름이 있는 기능 75개.
- 브리핑의 87은 시트 데이터 행 수이다. 상세 문장이 다음 행으로 이어진 12행(데이터 밸런싱 3, 디스크 격리 2, 토폴로지 6, 클러스터 관리 1)을 포함한 값이라 기능 단위와 다르다.
- 이 문서의 KEEP: 40개. 목표: 40개(브리핑 목표 구간 40–45, 소분류 75개의 53%).
- 기준: GS·조달 베이직에 필요한 운영 최소 기능, 시험 조합을 키우는 고급·성능·이기종 기능은 옵션.
- 재민 미확정 휴리스틱에 따른 초안이다. 고객 발송 문서가 아니다.
